# Retail SQL Analysis

## Project Overview
This project focuses on analyzing retail transaction data using SQL and relational database concepts.

The analysis includes:
- customer behavior
- revenue analysis
- country-level sales
- transaction patterns
- product trends

## Tools Used
- MySQL
- SQL
- Power BI (in progress)

## Dataset
Online Retail Dataset

## Skills Demonstrated
- SQL querying
- JOIN operations
- GROUP BY and HAVING
- Aggregate functions
- Data analysis
- Relational database understanding
