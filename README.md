# Retail SQL Analysis

## Project Overview
This project focuses on analyzing retail transaction data using SQL and relational database concepts.

The analysis includes:
- customer behavior
- revenue analysis
- country-level sales
- transaction patterns
- product trends

## Tools Used
- MySQL
- SQL
- Power BI (in progress)

## Dataset
Online Retail Dataset

## Skills Demonstrated
- SQL querying
- JOIN operations
- GROUP BY and HAVING
- Aggregate functions
- Data analysis
- Relational database understanding

## Project Status
Ongoing

## SQL Analysis Examples

### 1. Dataset Size Analysis
This query counts the total number of rows in the retail dataset.

Purpose:
- understand dataset scale
- validate successful data import
- estimate analysis complexity

### 2. Price Distribution Analysis
This query analyzes minimum, maximum and average product prices.

Purpose:
- identify pricing range
- detect unusual values or outliers
- understand overall pricing behavior

### 3. Revenue by Country
This query calculates total revenue generated by each country.

Purpose:
- identify top-performing markets
- compare country-level sales performance
- support business expansion analysis

### 4. Customer Distribution by Country
This query counts distinct customers by country.

Purpose:
- understand customer concentration
- identify strong customer markets
- compare customer base distribution
